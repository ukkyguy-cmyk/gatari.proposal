01 / 08
WHY NOW

「バリアフリー」は、
設備の話で
止まっている。

スロープがあれば、十分か。
点字ブロックがあれば、安心か。
設備を変えても、体験は変わらない。

本当のインクルーシブは「あなたのために作った場所」ではない。
「誰もが同じ場所で、それぞれの世界を生きられる」こと。

そのために必要なのは、設備ではなくレイヤーだ。
Aurisは、そのレイヤーを現実空間に書き込める唯一のプラットフォームだと考えている。

CURRENT STATE — 現状

設備が先、体験が後。

車椅子スロープ・点字ブロック・多目的トイレ。物理的バリアフリーは整備されつつある。しかし「この公園に来ても楽しめない」という感覚は変わっていない。設備は来られる条件を作るが、体験は作れない。

VISION — 目指す姿

体験が先、設備が後。

Aurisが空間にレイヤーを書き込む。視覚障害者には音声ナビ、発達障害者には静かなルート、子どもには恐竜の世界。物理設備を変えずに、その人に合った公園体験が生まれる。

02 / 08
USE CASES

ひとつの公園に、
複数の世界が
重なっている。

🦖

恐竜体験学習

子どもが公園を歩くと足音が近づき、遠吠えが聞こえ、解説が空間から流れる。公園全体が没入型の教室になる。教育コンテンツをノーコードで更新できるため、季節・学習テーマに合わせて入れ替え可能。

Auris活用：位置連動の音声演出 / 子どもの動きに反応するインタラクション / ノーコード更新
🚶

駅から公園への安全エスコート

東あずま駅〜東あずま公園の導線を音声ナビで案内。信号・段差・曲がり角のタイミングで音が変わる。視覚障害者が「行ったことのない公園」に単独で行ける世界を作る。

Auris活用：3次元位置認識による動的ナビ / 多言語切り替え / 常時サポートモード
♾️

ほんとうのインクルーシブ公園

盲・ろう・肢体不自由・発達障害。それぞれに違うレイヤーが重なる。同じベンチに座りながら、それぞれの人が最適な公園体験を受け取る。「設備を変えずに体験を変える」Aurisの特性がここで最大限に活きる。

Auris活用：ハンディ別レイヤー設計 / cmオーダー3D位置認識 / 座る・立つ動作への対応
🌿

ナチュラルな棲み分け

静かにいたい人・にぎやかに遊びたい人・一人でいたい人が、看板なしに自然と自分のゾーンを見つける。音と体験が見えない地図を描く。行政が「静粛ゾーン」と看板を立てるのではなく、体験が人を誘導する。

Auris活用：位置連動の空間演出 / ユーザー属性別レイヤー / 動的ゾーニング

PERSONA × METHOD

仕掛ける側が、
先に盲目に
なる。

ペルソナは障害者ではなく、健常者だ。
目隠しをした瞬間、全員が「盲目初心者」になる。
共感は説明から生まれない。体験から生まれる。

01
BOTH EYES OPEN — 両目で見る
通常の視野。まだ「自分には関係ない」と思っている。
02
NARROW FIELD — 視野が狭まる
周辺視野が消える。空間の圧迫感が出始める。足元が不安になる。
03
BLUR — ぼかし
輪郭が溶ける。音と気配だけが頼りになる。Aurisの音声が「見える」ようになる瞬間。
04
ONE EYE — 片目隠し
奥行きが消える。距離感が掴めなくなる。段差の恐怖を初めて理解する。
05
BLACKOUT — 両目隠し
完全な暗闇。音だけで歩く。恐怖が、共感に変わる瞬間。設計者の意識が変わる。
段階的に世界が狭まるから、フォーカスがぶれない。
「怖い」という感情が、「なんとかしたい」に変換される設計。
これを利害関係者向けアジェンダの冒頭5分として組み込む。
